# Actividad Unidad 3 — Sistema de nómina

Repositorio del proyecto académico en Java, con informe técnico, consigna, diseño, pruebas y evidencia local.

El estudiante informa que trabajó sin compañeros. Codex asistió en la implementación y documentación; el README detalla el alcance y los pendientes académicos.

## Archivos principales

- `README.md`: descripción, reglas implementadas y pasos de ejecución.
- `pom.xml`: configuración de Maven.
- `src/`: implementación Java y pruebas unitarias.
- `docs/Consigna_Actividad_Unidad_3.pdf`: consigna proporcionada.
- `docs/Informe_Tecnico_Actividad_U3_Nomina.docx`: informe técnico.
- `docs/Metodologia_y_Diseno.md`: decisiones de diseño y supuestos.
- `docs/evidence/` y `screenshots/`: resultados locales y capturas con metadatos.

La carpeta `docs/` incluye los pendientes académicos que requieren validación. El registro Maven tiene sus rutas locales absolutas redactadas por privacidad. El repositorio personal no acredita aportes de un grupo y la exposición en video aún debe realizarse si la consigna aplica al caso individual.
