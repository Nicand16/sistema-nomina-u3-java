# Actividad Unidad 3 — Sistema de nómina

Desarrollé individualmente un sistema académico de nómina en Java, con informe técnico, consigna, metodología, pruebas automatizadas, registros de ejecución y guion de exposición.

## Material principal

- `README.md`: resumen del sistema y comandos de ejecución.
- `pom.xml`: configuración Maven.
- `src/`: implementación Java y pruebas unitarias.
- `docs/Consigna_Actividad_Unidad_3.pdf`: consigna original.
- `docs/Informe_Tecnico_Actividad_U3_Nomina.docx` y `.pdf`: informe técnico.
- `docs/Metodologia_y_Diseno.md`: diseño, reglas y resultados.
- `docs/Guion_y_Estructura_Exposicion_U3.docx`: guion y orden de diapositivas.
- `docs/evidence/`: salida textual de las pruebas y la demostración.
- `screenshots/`: capturas de esas salidas y sus metadatos.

Para los parámetros no especificados en el enunciado adopté supuestos de demostración. Los datos de ejemplo son ficticios y se usan con fines académicos.
